# Amazon Clone

A responsive e-commerce application inspired by Amazon, built with React and JavaScript. The application allows users to browse products, manage a shopping cart, save items to a wishlist and complete a simulated checkout experience. Developed as a frontend project, it demonstrates component-based development, state management, product interactions and integration with Firebase.

## Features

- **Product Browsing:** Browse products displayed in a responsive product grid.
- **Shopping Cart:** Add products, adjust quantities and manage cart items.
- **Wishlist:** Save products for later.
- **Product Details:** View individual product information.
- **Order Confirmation:** Complete the checkout flow and view order confirmation.
- **Payment Integration:** Stripe integration for the checkout experience.
- **Firebase Integration:** Firebase services for application data and functionality.

## Installation and Setup

### 1. Clone the repository

git clone https://github.com/NompiloKhensani/my-amazon-clone.git

### 2. Navigate to the project folder

cd my-amazon-clone

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

### 5. Access the application

http://localhost:5173
